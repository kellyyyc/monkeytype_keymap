Monkeytype Keymap+

Help

Enable the keyboard on Monkeytype

  1. Open monkeytype.com.
  2. Open Settings, then go to Appearance → Keymap.
  3. Enable one of the keyboard modes: Static, React, or Next.
  4. The on-screen keyboard will now appear while using Monkeytype.

Change key colors

  1. Select individual keys or click Select All.
  2. Use Text Color or Background Color to choose your colors.
  3. Click Save to apply your changes.

Alternatively, you can click Rainbow to apply a preset color layout and then save the theme.
This can make it easier to learn which fingers to use when practicing touch typing.
