# Monkeytype Keymap+

## Description

Monkeytype Keymap+ is a Chrome extension that lets users customise the colors of the on-screen keyboard on [Monkeytype](https://monkeytype.com).

Users can select individual keys and change their text or background colors to create a personalised keyboard layout. Settings are automatically saved and applied whenever Monkeytype is opened.

The extension also includes layout options and a rainbow preset that helps users see which finger correspond to each key.

## Features

- Customise the text and background colors of individual keyboard keys
- Select multiple keys at once
- Apply a rainbow preset for touch-typing practice
- Choose between QWERTY, Dvorak, and Colemak keyboard layouts
- Enable an Angle Mod layout for the rainbow preset
- Save settings using Chrome's built-in Storage
- Apply saved colors when Monkeytype loads
- Supports Monkeytype's Static, React, and Next keymap options
- Includes Help, Settings, Privacy Policy, and Contact pages

## Install

Install Monkeytype Keymap+ from the [Chrome Web Store](https://chromewebstore.google.com/detail/monkeytype-keymap+/jkkiaonhfpneiiiljpagbhdfknpmmofd).

## Usage

1. Open Monkeytype.
2. Enable the on-screen keyboard in Monkeytype's keymap settings.
3. Open Monkeytype Keymap+ from the Chrome extensions menu.
4. Select the keys you want to customise.
5. Choose text and background colors.
6. Click **Save**.

To apply the rainbow preset:

1. Open Monkeytype Keymap+.
2. Click **Rainbow**.
3. Click **Save**.

To change keyboard layout or rainbow preset behaviour:

1. Open the extension popup.
2. Click the settings icon.
3. Choose a keyboard layout or enable Angle Mod.

## Privacy

Monkeytype Keymap+ stores your keyboard customisation settings using Chrome's built-in storage system. These settings are only used to save your preferences.

The extension does not collect, transmit, sell, or share any personal information.
